The guide walks through building a documentation site with documango, from
the first Markdown file to a deployed website.

- [Writing pages](writing-pages.md): how files and folders become pages, URLs,
  and the sidebar, and how to control titles and ordering with front matter.
- [Markdown](markdown.md): the Markdown syntax documango supports, with
  examples.
- [Themes](themes.md): choosing a light and dark color scheme, or using your
  own.
- [Deploying](deploying.md): building a static site and publishing it,
  including to a subpath such as a GitHub Pages project site.

For a list of every command, flag, and field, see the
[reference](../reference/index.md).
